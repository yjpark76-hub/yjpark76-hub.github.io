1. 앱 소개 / About

증시배달부 업로더는 유튜브 채널 '증시배달부' 운영자가 자신의 채널에 쇼츠 영상을 업로드하기 위해 사용하는 개인용 프로그램입니다.
"증시배달부 업로더" is a personal tool used only by the owner of the YouTube channel "증시배달부" to upload Shorts to their own channel.

2. YouTube API 서비스 사용 / Use of YouTube API Services

이 앱은 YouTube API 서비스를 사용합니다. 이 앱을 사용하면 YouTube 서비스 약관(YouTube Terms of Service)에 동의하는 것으로 간주되며, Google의 개인정보 처리는 Google 개인정보처리방침(Google Privacy Policy)을 따릅니다.
This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy linked above.

3. 수집·이용하는 정보 / Data accessed

  • 운영자 본인 채널의 기본 정보(채널 이름·ID)를 조회해 올바른 채널인지 확인합니다. / Reads the owner's own channel title and ID to verify the target channel.
  • 운영자 본인 채널에 동영상과 제목·설명·태그를 업로드합니다. / Uploads videos and their metadata to the owner's own channel.
  • 다른 사용자의 개인정보나 YouTube 데이터는 수집·저장·공유하지 않습니다. / No data of other users is collected, stored or shared.

4. 저장 및 공유 / Storage and sharing

OAuth 인증 토큰은 운영자 본인 PC에만 저장되며 외부 서버로 전송되거나 제3자와 공유되지 않습니다. YouTube API로 받은 데이터는 업로드 결과(동영상 ID) 외에 저장하지 않습니다.
The OAuth token is stored only on the owner's local PC and is never sent to any server or shared with third parties. No YouTube API data is retained except the resulting video ID.

5. 삭제 및 권한 철회 / Deletion and revoking access

사용자는 언제든지 Google 보안 설정 페이지(Google security settings)에서 이 앱의 액세스 권한을 철회할 수 있습니다. 권한 철회 또는 요청 시 PC에 저장된 인증 토큰을 즉시 삭제합니다(최대 7일 이내).
You can revoke this app's access at any time via the Google security settings page. Upon revocation or request, the stored token is deleted immediately (within 7 days at most).

6. 문의 / Contact

유튜브 채널 '증시배달부' 정보란을 참고해 주세요. / Please use the contact information on the "증시배달부" YouTube channel.
